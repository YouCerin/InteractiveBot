# 0.3.3 — 人设重写、两层记忆与她自己的日记

## 概述

0.3.3 的主体是三件事：**出厂人设按「写法四戒」重写**（只给倾向、不给示范句，安全边界一条不松）；**记忆从三层收敛到两层**，群聊不再单独存档，群里说的话归到**说话人自己**名下，同时删掉三条无人使用的写入通道；机器人**有了自己的日记**（一个纯文本 `.jsonl`，一天最多三条，只写不改不删，不进入提示词）。

此外补齐四块能力：对话上下文里的图片、按上下文自写的垫场白、统一出站投递管线、以及从真实聊天里学来的语感画像。

本版还修复了两处线上问题：**隐私闸门拦下回复后模型并不知情**（会以为自己说过），以及**同时拉起两个协议端导致端口冲突**（表现为「端口被占用、机器人不在线」）。

完整技术说明与决策记录见 [`docs/0.3.3-release-notes.md`](https://github.com/YouCerin/InteractiveBot/blob/main/docs/0.3.3-release-notes.md)。

## 新增能力

| 模块 | 说明 |
|---|---|
| 人设重写 | 按四戒重写出厂人设：示例句清零、四戒做成可自动核对的判据、环境事实（工具、路径、时间）一条不丢。运行期加载人设，改动需重启 |
| 两层记忆 | 全局 `MEMORY.md` 与个人 `memory/people/<QQ>.md`；群聊层下线，旧群档归档至 `memory/.migrated/groups/`，不再注入 |
| 她的日记 | `diary/diary.jsonl`，一行一条 `{时间,心情,内容}`；只有「写一条」「看最近几条」两个动作，一天最多三条、每条一两句，隐私七类不落盘。工具描述为「想到什么就写什么」，未规定题材与时间 |
| 上下文取图 | 「先发一张图、紧接着叫它」时模型能看到那张图（按需下载与自动附带两种模式） |
| 垫场白（AI 档） | `humanize.interim.mode = ai`：由模型按上下文自己决定要不要先说一句、说什么；拿不到时退回话术池 |
| 出站管线 | 统一到 `deliver()`：会话级串行链、投递回执（说了但没发出去会告知模型）、跨通道投递（默认关闭，白名单控制） |
| 语感 | 候选池 → 人工评审 → 画像三级流水线；画像全局生效，不按群、不按「闲聊/办事」区分 |
| 隐私闸门（出站） | 判定装在唯一出口上，覆盖交互回复、定时任务、服务器事件播报；命中即替换为固定话术，并把「未发出」告知模型 |
| 协议端启动锁 | `cache/snowluma-launch.lock`：并发启动时第二个改为等待，不再拉起第二个实例 |

## 修复

1. **隐私拦截后模型不知情**：回复被隐私闸门替换为固定话术后，模型那一轮已结束，下一轮仍按「我说过了」行事（真机出现过反问对方「你没刷到？」）。现在停用原文并以固定话术发送，同时在下一轮提示词中以 `[隐私闸门]` 说明「这条没发出去、对方实际看到什么」，且不回显原文。
2. **出站隐私闸覆盖面不全**：此前只对交互回复生效，定时任务与服务器事件播报不经过该闸。现将判定移入唯一出口（`deliver()`）与回合级投递（分条前），主动回合返回实际发出的正文用于记账。
3. **协议端重复启动**：同一秒拉起两个实例会把端口分掉（一个占 3000/3001，另一个网页端退让到 5100），控制台指向失败的那一个，并产生 SQLite 写锁与重复登录。现以文件锁互斥，超时残留锁可接管。
4. **提示词中的「承诺」教学已移除**：承诺通道整条删除（模型不再被要求在回复里写承诺标记）。
5. **发布验收脚本的相对路径假报**：`check-release-package.mjs` 收到相对路径时会双重拼接，导致包内界面自检误报失败；现入口统一解析为绝对路径。

## 运行前置条件

1. 需预先安装 DeepSeek Harness 桌面版（本包不含）。安装后在控制台「高级」页填写路径，或用 `start.bat --check` 查看自动解析结果与来源。
2. QQ 协议端 SnowLuma 需自行下载（其许可证不允许随第三方分发包分发）。
3. 需要模型 API Key：在控制台「高级」页填写一次即可；已配置 DSH 桌面版凭据的可直接复用。
4. `config.json` 含明文密钥（模型 Key、SnowLuma token），请勿外发或提交至版本库。

## 升级（0.3.2 → 0.3.3）

1. 解压至新目录，可与旧版本并存。
2. 复制旧目录的 `config.json`（必须），`workspace-qq/` 与 `logs/` 按需复制。`config.memory.affect.*` 已随情绪通道删除，旧配置里的未知键会被忽略，不必手改。
3. **记忆布局有变化**：`memory/groups/*.md` 与 `<群号>-slang.md` 不再注入，桥接启动时会归档到 `memory/.migrated/groups/`（只搬不删）。个人档 `memory/people/<QQ>.md` 保持原样。
4. **配方目录有变化**：从 `memory/recipes/` 移到包级 `recipes/`。旧目录仍只读兼容；需要物理搬家时运行 `node tools/migrate-recipes-dir.mjs`（默认预演，`--apply` 才搬）。
5. 旧备份与快照可用 `node tools/prune-memory-archives.mjs` 清理（默认预演：备份保留 30 天内、快照保留最新 20 份）。
6. 停止旧桥接后再启动新版本（进程守卫会拒绝第二个实例）。
7. 执行 `start.bat --check` 确认环境；`start.bat --doctor` 会实际探测一次协议端。

## 已知限制

1. 控制台授权文件为明文，可被模型伪造：能够防御外部访问者，无法防御模型主动伪造。彻底解决需要宿主层透传会话身份。
2. 日记功能尚未在真实对话中触发过：落点、条数上限、长度与隐私闸均为离线校验。日记不进入提示词，因此「她什么时候想写」完全由模型自行决定。
3. 隐私闸门只做字面判定（七类，校验位/算法参与），不理解语义；跨句拼凑的个人信息不在判定范围内。
4. 群聊层下线后，原本只在该群成立的信息（群规、群内梗）只能写进个人档，群与群之间不再有结构性隔离。
5. 语感画像由离线蒸馏产生，加载一次；更新画像需重启桥接。
6. 发布包尚未在第二台独立设备上完成端到端验证。
7. 本项目使用第三方协议端登录个人 QQ，违反《QQ 用户协议》，账号可能被限制或封禁；相关的延迟与频率限制仅降低特征强度，不构成保证。
8. 本项目与 DeepSeek / DeepSeek Harness 及其权利人无隶属、赞助或背书关系。
