## 一句话

**服务器里的玩家可以随时和后端的小鲸鱼说话；服务器出问题时它报告且只报告一次，并尝试一次重启；
重启失败就向管理员求助并等指令。** 另外它现在能**问出一台服务器的情况**（人数 / TPS / 连通），
**管理员可以从三个入口下控制台指令**（op 级别），而且这一切**不需要任何服务端插件或模组**。

## 这一版新增了什么

| | 能力 | 一句话 |
|---|---|---|
| ① | **服务器监测** | 连续 N 次连不上才算 `down`（防抖动误报）；「正在启动」是**独立状态** —— 模组服冷启动 18~60 秒，不区分就会"还在加载时被判 down 并再拉一个"（两个 JVM 同写一个世界 = **存档损坏**） |
| ② | **启动接管** | 桥接启动时：端口活着 + 归属是我 ⇒ 接管；端口活着但不是我的 ⇒ **只报告不动手**；端口不通 ⇒ 拉起来并**等端口真的开放**才算起来。判据是"**端口不通才拉**"，不是"归属不是我" |
| ③ | **重启编排** | 归属判据 = `pid@进程启动时刻`（不是"名字里有 java"）；优雅停服（RCON `stop`）→ 等端口释放 → 拉起 → 等端口开放；冷却 + **同一次故障最多试一次**，成功一次后计数归零；等不到就**如实说没起来**，不谎报 |
| ④ | **完整控制台（op 级）** | 三条入口：本机网页 / 群里 `\mc [id] <命令>`（**本地拦截、不经模型**）/ 模型调工具 / 游戏内管理员。开关 `servers[].commandFromQQ` **默认关**，且有**一处硬闸**（判权限在碰网络之前） |
| ⑤ | **游戏内对话** | 玩家在服里说 `\mc bind` 拿码 → 群里发 `\mc bind <码>` **当场绑定**（**不用 @ 我**）；已绑定的玩家说话会进模型，回复走**公屏** `tellraw @a` 且带 `<小鲸鱼> ` 前缀（不上色，模仿正常玩家）；未绑定者说话**不进模型**（零成本）。★ 不需要任何服务端插件/模组 —— 读的是桥接自己拉起的那个服务端的控制台日志 |

外加**定时任务**（到点主动说一句，**恰好一次**）、**任务/服务器两个页签**，
以及六处真机缺陷修复。

### 这一版最贵的三个修复（都是"静默出错"）

1. **保存一次服务器条目，RCON 密码就没了** —— 界面从不回显密码 ⇒ 保存时不带这个字段 ⇒
   后端"整条替换"把它补成空串，**全程不报任何错**。表现是控制台突然说「⚠️ 没配 RCON 密码」。
   已按"留空 = 不改 / 填了 = 覆盖 / 勾清除 = 删"三种意图重做，并加了回归断言。
2. **`GET /api/config` 把 RCON 密码明文发给了浏览器** —— 密码住在 `servers[]` 的**数组元素**里，
   所以它上不了那张固定路径的字段白名单。已strip，并且**必须与第 1 条一起修**（只修泄密会更丢密码）。
3. **游戏内说话会把「先应一声」发进 QQ 私聊** —— 通道串味。游戏内那条通道现在完全跳过过渡语。

### 收尾批次（0.3.2 打包前）

- **服务端的 `server.properties` 与 `eula.txt` 也能在编辑栏里直接改**：游戏端口、
  `enable-rcon`、`rcon.port`、`rcon.password`、以及**「同意 EULA」**。
  它治的是"**改了没用**"——我们那份配置只决定**往哪儿连**，服务端监听哪个端口、
  肯不肯启动，是**它那份文件**的事，而那份文件**只在启动时被读一遍**。
  界面会把两边**对不上**的项直接列出来，写服务端那份的同时**同步我们这份**，
  并如实说「**要重启服务端才生效**」。只改被管的那几行（其余逐字保留）、写前备份、写前重读。
  ★「同意 EULA」是**同意条款**的动作，必须你自己点那个按钮（旁边给条款链接），不预勾。
- **「密码忘了 ⇒ 把服务端那份抄过来」**：密码明文存在两边，而服务端那份是**权威** ⇒
  一键抄进本桥接的配置，**一次重启都不用**，而且**你不需要看到那个密码**（响应里只有类别，没有值）。
- **换一台设备后「控制台界面未构建」不再是谜语**：`config-ui/dist` 是**随包发出去的一部分**
  （很多打包/复制工具看着 `.gitignore` 里那行裸 `dist/` 就跳过它）。现在那一页会写出
  **它找的是哪条路径**、点明最可能的原因、并给出两条修法（重新完整拷贝 / 自己 `npm run build`）——
  它**不影响机器人回话**。`node src/index.mjs --check` 也会报这一项。
- **bot 的对话在 DSH 侧栏里是「未分组」** —— 查清了机制（DSH 走 SDK 那条路不带工作区，
  只能改它的注册表），加了一个 dev-only 工具 `tools/link-dsh-workspace.mjs`（默认干跑）。

## 四件必须先知道的事

1. **需要先装 DSH**（DeepSeek Harness 桌面版）—— 本包不含它。装完在控制台「高级」页填路径，
   或直接让它自动查找（`start.bat --check` 会告诉你它解析到了哪、来源是什么）。
2. **需要自己下载 SnowLuma**（QQ 协议端）。
3. **需要你自己的模型 API key**：控制台「高级」页填一次即可；已经装过 DSH 桌面版并填过 key 的人
   **不用重复填**（本程序会复用 DSH 的凭据）。
4. **`config.json` 里会是明文密钥**（模型 key 与 SnowLuma token）—— 别外发、别提交到 git。
   它**刻意不进 git、也不进发布包**。

## 升级（0.3.1 / 0.2.9 → 0.3.2）

1. 解压到**新目录**（新旧版本并存没问题，包名只差版本号）；
2. 把旧目录里的 **`config.json` 拷过去**（只有它必须带；`workspace-qq/` 是记忆与工作区、
   `logs/`、`cache/` 想留就一起拷）。0.3.2 只**新增**配置键，缺的会用默认值补上 ——
   沿用旧 `config.json` 不会坏；
3. **停掉旧的桥接进程再启动新的** —— 进程守卫**会拒绝第二个实例**（两个会抢同一份 OneBot 事件流）；
4. `start.bat --check` 看一遍（DSH 在哪、协议端在不在、配置缺什么）；
5. **想用 Minecraft 那一层**（默认完全关闭、一次网络请求都不发）：在控制台「服务器」页签加一台，
   填 `id` / `host` / `port` / `rconPort` / `password`、**`cwd`（服务端根目录）**与**启动可执行文件
   `startExe`**（推荐形状：不走 shell，否则拿到的 pid 是 `cmd.exe` 的、归属永远判不出来 ⇒
   重启能力形同虚设），然后就能在那一块里直接打开 `enable-rcon`、写游戏端口、**同意 EULA** ——
   这几项改的是**服务端那两个文件**，**要重启服务端才生效**。

## 取证（这一版怎么被验证过）

```bash
cd packages/qq-bridge && npm test        # 84 套离线校验，不需要 QQ、不需要 DSH、不花钱
node src/index.mjs --servers             # 服务器那一层：配置 + 监测状态 + 归属 + 重启状态
node src/index.mjs --servers --probe     # 真连一次，只用只读命令
node src/index.mjs --ui                  # 手上这份界面产物是不是当前源码构建的
```

- 测试链 **84 套**，本次发布前 `exit 0`（含 `verify-route-scope` 那种"审真实接线"的词法守卫 ——
  这一版栽过一次**接线级缺陷纯函数断言抓不到**的事故：任务页签四条接口在真实运行时全部抛
  `ReferenceError`，而 81 套测试全绿）。
- 界面产物与源码同步由 `--ui` 核对（构建溯源写在 `config-ui/dist/ui-build.json`）。
- 发布包按清单组装：**用户数据（`config.json` / `workspace-qq` / `logs` / `cache` / `snowluma`）
  绝不进包**，有断言盯着；包内 `config.json` 与 `config.example.json` 逐字节相同。

## 已知边界（如实列，完整 13 条在发布说明里）

1. **控制台授权文件是明文、模型能伪造** —— 它挡得住**外部陌生人**，挡不住**模型主动恶意伪造**
   （要堵它得让宿主把会话身份透传到 MCP 层，那是改上游契约）。
2. **游戏内没有"真·斜杠命令"**：现在靠游戏内**聊天**形态（`\mc bind`，反斜杠）——
   以 `/` 开头的输入会被服务端当命令、而那句"未知命令"**不写进控制台日志**，我们看不到。
   要真命令 / 推送式事件 / 第二因子，需要**单独的服务端插件或模组**：本版**刻意不写服务端代码**。
3. **只有本程序拉起的服务端才有控制台日志**（别人手动起的服读不到东西，日志里会有一行说明，
   **这不是故障**）。
4. **身份有一条"按名字回退"的路**：它的强度**等于服务端对名字的认证**（正版验证关掉时，
   改名就能冒名）。想把这条收紧可以只认 UUID。
5. **播报默认不自动**：服务器 `down` 就自动播报到群里 = 把"服务端的一部分事实"交给
   **任何能让它掉线的人**（重启一下、打崩它，群里就会响）⇒ 事件型任务的 `announce` 默认 `manual`。
   但"**尝试一次重启**"不受它影响（处置与播报是两件事）。
6. **发布包没有在第二台干净机器上验证过**能否跑起来（这一条从 0.2.7 打包时就挂着）。
7. **本项目的做法违反《QQ 用户协议》**：第三方协议端登录**个人 QQ**，账号可能被限制或封禁。
   请只用自己的小号试、别在重要群刷。那些"拟人延迟 / 频率上限"只是**降低**特征强度，**不是**保证。
8. 本项目**非官方**：与 DeepSeek / DeepSeek Harness 及其权利人**没有**任何隶属、赞助或背书关系。
