## 3. 减法：两处合并 + 一次清理

### 3.1 合并「QQ 功能」→「扩展」

* **依据**：`McpTab.tsx` 整页只有两个控件（`mcp.enabled` 开关 + `mcp.toolTimeoutMs`），
  而 `mcp` 正是新插件表里的一格（`src/plugins.mjs` 的 `qq-tools`，`hot: false` 已取证）。
* **做法**：插件卡里放"开关 + 关掉会怎样 + 需重启的原因"，`toolTimeoutMs` 移进这张卡的展开设置；
  删掉 `McpTab.tsx` 与它的 TabsTrigger/TabsContent。
* **风险**：低。唯一要注意的是 `mcp.enabled` 是 **cold**（要重启），卡上必须显示出来。

### 3.2 合并「触发」→「人设」

* **依据**：两个页签各 3.6–3.8KB，是全场最小的两个，语义相邻（"它是谁、怎么说话" +
  "什么时候该回"），共用一个"人味层"心智模型；分开的代价是使用者在两页之间来回找。
* **做法**：`PersonaTab` 里加一节「什么时候回我」（原来的 `TriggerTab` 内容，含关键词表与告警）；
  删掉 `TriggerTab.tsx` 与它的 TabsTrigger/TabsContent。
* **风险**：中低。「触发」里有关键词体检（`lintKeywords` 告警）与群聊开关的**风控文案**，
  合并时必须原样保留（`CONFIG-UI.md` §2.3 的字段说明是硬要求）。

### 3.3 清理 38 个从未被引用的模板文件

名单（由仓库里的探针产出：`node mocks/probe-ui-deadcode.mjs`，`components/ui/` 下）：

```
accordion alert aspect-ratio avatar breadcrumb button-group calendar carousel chart
collapsible command context-menu drawer dropdown-menu empty field form hover-card
input-group input-otp item kbd menubar navigation-menu pagination popover progress
resizable scroll-area separator sheet sidebar skeleton sonner spinner toggle
toggle-group tooltip
```

外加 `src/App.css`、`src/hooks/use-mobile.ts`。（`src/index.css` **不是**死代码 ——
它由 `main.tsx` 以副作用导入；探针第一版漏认那种写法、把它误报成死代码，已修。）

* **依据**：从 `main.tsx` 出发的 import 图可达性（`mocks/probe-ui-deadcode.mjs`，支持 `@/` 别名、
  省略扩展名、`import 'x'` 副作用导入）；`sonner.tsx` 也在里面，因为 toast 用的是 npm 包而不是这个包装组件。
* **做法**：删文件 → 重新跑一次探针确认没有新增死代码 → `npm run build` 必须通过。
* **风险**：低，但**必须**在删之前跑探针（不要凭名字删）；`ui/` 里被别的 `ui/*` 引用的
  组件（如 `sidebar` 依赖 `sheet`/`tooltip`）会一起被判为死代码，这是对的 —— 它们同样不可达。

## 4. 「界面逻辑」的具体修法（四处）

### 4.1 生效方式要在**开关旁边**说清（本版最重要的一条）

现状：`Home.tsx` 的 `save()` 无论改什么都弹「已保存。需要**重启机器人才会生效**」。
而 0.2.2 起，「扩展」页的开关是**即时生效**的 —— 文案写死就会出现"界面说要重启，其实不用"。

修法：
* 保存提示**按接口返回值渲染**（`restartRequired` / `hint` 由后端给，界面别自己编）；
* 每个页签标题旁加一个**生效方式徽标**：`即时` / `需重启`（数据来源：本页签有没有即时通道）；
* 「扩展」页里每张卡的徽标由 `hot` / `restartRequired` 决定，**cold 的必须把 `why` 显示出来**。

### 4.2 未保存改动要看得见

现状：只有底部浮条（`Home.tsx:460-484`）体现 dirty；切到别的页签就看不出"哪一页改过"。
修法：TabsTrigger 上加一个小圆点（`dirtyTabs` 已有数据基础：`patch()` 里知道改的是哪个前缀）。

### 4.3 扩展页不要跟着主轮询每 2–3 秒刷新

现状：`/api/status` 每 2–3 秒轮询一次。扩展清单（`/api/extensions`）会做文件系统扫描与模块
`promptSections()` 调用，**没必要跟着每 3 秒跑**。
修法：进入页签时拉一次 + 操作后重拉 + 手动「刷新」按钮；`/api/status` 的轮询保持不变。

### 4.4 去掉重复的空态/错误文案

现状：`Home.tsx:339-354` 的"你看到的是旧界面"提示，与各卡片自己的空态文案有重叠；
`PreflightCard` 的"启动条件"与概览页顶部的状态条也在讲同一件事的两半。
修法：统一成"**一处说结论（顶部）、一处说下一步（卡片）**"，并在 `config-ui` 里删掉那句重复的
自我解释（保留后端给的 `why`/`advice` 原文，别自己编）。
