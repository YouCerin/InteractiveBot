================================================================
  首次使用（约 15 分钟，不用懂编程）
================================================================

这是一个 QQ 机器人：你在 QQ 里跟它说话，它由一个 AI（DeepSeek）
来回答，还能在你允许的范围内操作文件、联网查资料、用 QQ 原生的
功能（戳一戳之类）。

这个包里**已经自带**了运行需要的 Node 环境，你不用装 Node，
也不用敲任何命令。但下面 4 样东西要你自己准备。


----------------------------------------------------------------
第一步：装 4 样东西（都有下载地址）
----------------------------------------------------------------

【1】QQ 桌面版（电脑版 QQ）
     下载：https://im.qq.com/
     说明：机器人是"借用"你自己电脑上的 QQ 来收发消息的，
           所以必须先装好 QQ，并且能正常打开登录。

【2】DeepSeek Harness（简称 DSH，机器人的"大脑"）
     下载：https://github.com/deepseek-ai/deepseek-harness/releases
     说明：★ 这个包**不含**它，必须自己装（它很大）。
           装完不用做任何配置，机器人会自己去找它。
           ★ 如果上面这个地址打不开或找不到，就在搜索引擎里搜
             "DeepSeek Harness 桌面版 下载"，认准官方来源。

【3】SnowLuma（负责跟 QQ 通信的组件）
     下载：https://github.com/SnowLuma/SnowLuma/releases
     说明：① 选文件名里带 "win-x64" 的那个
           ② 选**不带** "-lite" 的完整版（自己带 Node，解压就能用）
           ③ 解压到一个固定的目录，比如 C:\SnowLuma\
           ★ 这个包也**不含**它：它的许可证不允许随别人的安装包一起发。

【4】模型 API Key（AI 回答要用的"钥匙"，一串 sk- 开头的字符）
     获取：https://platform.deepseek.com/
     说明：注册/登录后创建一个 API Key，复制下来。
           这个 key 是你自己账号的，用完的钱也从你自己账号扣。


----------------------------------------------------------------
第二步：启动机器人
----------------------------------------------------------------

1. 双击本目录里的【start.bat】
   （这是本目录**唯一**的双击入口。它启动完会把窗口停下来几秒，
     上面写着控制台与 SnowLuma 的地址，看到就可以关掉那个窗口 ——
     机器人是**后台**跑的，关窗口不等于关机器人。）
2. 它会自动打开一个网页（控制台），地址是 http://127.0.0.1:3410/
3. 第一次打开时，页面上会有醒目提示告诉你还缺什么，照着填即可

★ 关于图标：`start.bat` 在 Windows 里**永远显示默认的"白纸+齿轮"图标**，
  这是 Windows 的限制（资源管理器不给 .bat 显示自定义图标），不是文件坏了。
  想要带小鲸鱼图标的入口，就在"出问题了怎么办"那一节里跑那条命令 ——
  它会在本目录生成一个 `QQbot.lnk`。**不能直接把这个 .lnk 随包发给你**：
  它里面存的是绝对路径，在别人机器上会失效。


----------------------------------------------------------------
第三步：在控制台网页里填 3 个地方
----------------------------------------------------------------

页面顶部有几个页签（高级 / 协议端 / 触发 …），只填下面这几处：

【高级】页
   · API Key        → 把第一步拿到的 sk- 开头的 key 粘进去
   · 额外搜索路径    → 一般不用管（DSH 装在默认位置时自动找到）

【协议端】页
   · 如果是刚装好 SnowLuma：把它的目录填到"启动入口"里，
     例如 C:\SnowLuma\index.mjs
     （★ 填的是**文件**，不是文件夹）
   · 页面上如果显示"还没检测到 SnowLuma"，那里有下载入口和说明

【触发】页 / 名单设置
   · 管理员 QQ 号 → 填你自己的 QQ 号
     ★★★ 这一项不填 = **谁都不能用**，机器人一条消息都不回。
           这是故意的安全设计，不是坏了。
   · 群白名单     → 想让它在哪个群工作就填哪个群号，不填 = 群里不回

填完点页面上的「保存」，然后点「重启」让它生效。


----------------------------------------------------------------
第四步：让 SnowLuma 登录 QQ
----------------------------------------------------------------

SnowLuma 启动后，打开它的控制台：http://127.0.0.1:5099/
（如果打不开，先确认 SnowLuma 已经在运行）

· 首次启动会在控制台或日志里打印一个**一次性临时密码**，用它登录
· 登录 QQ **只支持扫码**：用手机 QQ 扫电脑上 QQ 窗口里的二维码
· QQ 和 SnowLuma 谁先开都行，但两个都要用**同一个 Windows 用户**运行


----------------------------------------------------------------
第五步：试一句
----------------------------------------------------------------

用你自己的 QQ（就是填进"管理员"的那个号）给机器人发一条私聊，比如：
   你好，你叫什么？

正常情况下会收到回复。第一次回复可能等几秒到十几秒 —— 它在思考。
★ 机器人**不会秒回**，这是刻意的（秒回容易被 QQ 判定为机器人）。
   如果等了半分钟还没动静，看下面"出问题了怎么办"。


----------------------------------------------------------------
出问题了怎么办（重要）
----------------------------------------------------------------

本目录里只有 `start.bat` 一个入口，自检靠它的两个开关。
**命令行怎么开**：在本目录空白处按住 Shift 点右键 →
「在此处打开 PowerShell 窗口」，然后输入下面任一条并按回车
（注意开头那个点和斜杠不能漏）：

    .\start.bat --check     只看配置文件本身对不对（不连网、不花钱）
    .\start.bat --doctor    真的去连一次 SnowLuma，告诉你到底哪一步没通

★ 想双击也行，但**双击默认是"启动机器人"**，不是自检。要看自检结果就按上面
  那样开个命令行窗口跑（双击时窗口会停一下让你看启动信息，但那不是自检）。

② 想要带图标的常用入口（可选）：在上面那个 PowerShell 窗口里跑这一条，
   它会在本目录生成 `QQbot.lnk`（带小鲸鱼图标，可以拖到桌面）：

    powershell -NoProfile -Command "$s=New-Object -ComObject WScript.Shell; $l=$s.CreateShortcut((Join-Path $PWD 'QQbot.lnk')); $l.TargetPath=(Join-Path $PWD 'start.bat'); $l.WorkingDirectory=$PWD; $l.IconLocation='assets\icon.ico,0'; $l.Save()"

   （为什么不能直接给你一个现成的 .lnk：它里面存的是**绝对路径**，
     在作者机器上生成的那份，到你机器上目标和图标都会失效。）

③ 常见现象对照：

   一条都不回
     → 最常见：管理员 QQ 号没填（空白 = 谁都不能用）

   控制台显示"没检测到 SnowLuma"
     → SnowLuma 没装、没解压，或者"启动入口"路径填错
     → 注意填的是 index.mjs 这个**文件**，不是 C:\SnowLuma 文件夹

   能收到消息但没有回复内容（或只回一句兜底话术）
     → API Key 没填或填错了

   协议端一直"令牌被拒" / 连不上
     → SnowLuma 那边的两个 token 和配置不一致；
       去 http://127.0.0.1:5099/ 的配置页复制正确的 token

   网页控制台打不开
     → 机器人没启动成功。看本目录 logs\bridge.log 的最后几行

③ 万能办法：把 logs\bridge.log 的最后 30 行复制出来问人/问 AI。


----------------------------------------------------------------
几件必须知道的事（安全与风险）
----------------------------------------------------------------

· 机器人只能读写在**本目录下的 workspace-qq 文件夹**里，
  碰不到你磁盘上的其他文件。这是刻意设计的权限边界。

· 你和机器人的聊天内容会保存在本机（workspace-qq 与 logs 目录里），
  不会自动上传到别处。但**别把整个目录发给别人**，里面有你的记录。

· 用第三方组件登录 QQ 属于非官方方式，**存在账号被限制的风险**。
  所以：只用自己的小号试、别在重要群里刷、别 24 小时秒回。

· 本目录的 config.json 里会存明文密钥（API Key、SnowLuma token）。
  不要把这个文件、更不要把整个目录发给别人或上传到网上。
