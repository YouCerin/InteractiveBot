## 1. 这一版解决的四类真实问题

| # | 以前的样子 | 现在 |
|---|---|---|
| **说了记不住** | 用户说"记住 X"、机器人回"好的记住了"，**磁盘上什么都没有**（写入通道只有"模型自愿写标记"，实测几十轮里提议接近 0） | 「记住 X」**不依赖模型必然落盘**（关键词直写），落不上就如实回执 |
| **记了等于没记** | 记忆只增不减，而注入有条数上限、新条目追加在文件末尾 → 刚记住的事**从此再没进过上下文**（完全静默） | 使用账本 + "刚写下的排最前"；并在体检里列出"最久没进过上下文"的条目（**只提示，不降权**） |
| **说错了改不掉** | 要么直接改掉旧条目（"我说错过什么"消失）、要么两条都留着都注入（模型拿到互相矛盾的两个事实） | 旧条目**只标注不删除**（`〔已被更正：…〕`）且不再注入；判据被实测逼窄到"显式 fix + 自指措辞" |
| **答非所问/复读** | 长会话里模型丢主线：反复重试同一条路、问过的话再问一遍 | 任务台账（"我在做什么"）+ 会话走向（"我们聊到哪了"）**两条轴**都注入 |

另外修掉的两处"说了做不到"：提示词长期教它用**不存在**的引用通道（现在真的有 `[reply:id]`）、
以及"看不了图"（能力一直都在，只是桥接把图片地址丢了）。

## 2. 新增能力（都能用）

- **本地语料库 + 中文检索**：搜"我上次说的那个…"（FTS5，中文 2 字自动走 LIKE 回退；**七类隐私不落库**、30 天 TTL、**不存媒体本体也不存路径**）
- **控制台界面补全**（本轮）：启动前置条件门控（**它为什么不说话**）、桥接日志面板、协议端账号列表（**只回摘要、绝不回 token**）、会话内历史检索、记忆条目检索、记忆写入统计 + 零写入告警、隐私拦截双侧统计
- **QQ 工具从 8 个加到 13 个**：表情回应、正在输入、转发（可附一句自己的话）、打包聊天记录、@全体次数
- **投递账本**：发送前落账 → 重启时把"上一次没确认发完"的回复**报出来**（★ **不自动重发**，理由见下）
- **人设加固**：反注入段 + "被指出错了先认" + 名字表变成**真的唤醒信号**（叫「小鱼」也能叫醒）

## 3. 这一版**刻意不做**的事（都有理由，不是漏了）

| 不做 | 为什么 |
|---|---|
| 记忆强度**衰减**（浮点权重） | 与既有决策 D9 冲突；"顺手加个权重"看起来自然，后果是**记忆被时间悄悄吞掉**且无人察觉。账本里连 `strength` 这类字段都有断言禁止出现 |
| 崩溃后**自动重发**未完成的回复 | 崩溃可能发生在"已经发出去、但还没标上"那一瞬间，**无法区分** → 自动重发会产生**重复回复**，而重复回复比漏一条更糟。只报出来，补不补由人决定 |
| 剥掉所有 `（…）` 旁白 | 中文里圆括号大量用于正常表达，全剥会吃掉正常回复的半句（误删内容是内容事故）；只剥一张极小白名单 |
| 发布包里带 SnowLuma | 它的许可证不允许随第三方包分发 |

## 6. 已知边界与待办（如实列出）

- **反注入段是提示词层的防线，不是硬墙**：它降低成功率，不能保证 100% 挡住。
- **"话头"提醒仍未在真机出现过**：它要求"机器人先问一句短的、用户再回一句"，这种形状的对话还没发生
  （离线断言已覆盖，取证命令：`node mocks/session-grep.mjs "他这一轮开口了"`，注意区分文档示例）。
- **纯陈述式事实覆盖不会自动标注**（"是 Forge"→"是 Paper"、不带 `fix` 措辞时两条都保留）——
  要认出它必须做语义判断，硬做会**吃掉真实记忆**。
- **单会话记忆条目超过 25 条时**，注入按"最近进过上下文"排序取舍；被挤掉的会在体检里列出来。

## 7. 收尾修正：记忆"注入面"与"读失败静默"（2026-09-27 晚）

在回答"记忆现在是怎么消失的"时核对了代码，改掉两条**静默**问题（第三条顺手一起改）：

| 问题 | 以前 | 现在 |
|---|---|---|
| **非 `- ` 开头的行永远不注入** | 只认 `- ` 行 → 散文式记忆**文件里有、模型看不到**，且不报错 | **除空行、纯分隔线、`#` 排版行外，所有非空行都注入**。真机：注入行数 **57 → 60**（多出的 3 行全是 `private-100000001.md` 里的真实内容） |
| **读文件失败三处静默** | 注入读文件 `return []`、篡改检测读文件 `continue`、列目录 `continue` —— 都**不留痕**，表现是"它突然忘了某件事" | 统一走 `warnReadOnce`：**每个文件只喊一次**（注入每轮都跑，逐轮刷屏会把该看的那行埋掉），日志说清后果与排查方向 |
| （顺手）**`#` 行不该当记忆** | —— | `#` 行按**排版/说明**处理。★ 这条是**真文件打回来的**：`memory/contacts.md` 里 6 行 `#` 是文件用法说明，真数据只有 2 行；第一版"所有非空行都注入"会把说明书喂给模型。⇒ **想让它被记住，就不要用 `#` 开头** |

**新增诊断工具**（这个问题以后还会有人问）：
`node mocks/probe-memory-injection.mjs` 列出每个记忆文件"哪些行会注入 / 哪些不会 / 为什么 / 超上限几条"；
加 `private:<QQ号>` 参数直接打印**某个会话真实的注入正文**。
